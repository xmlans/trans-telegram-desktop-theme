# Trans-telegram-desktop-theme

以跨性别旗帜的蓝、粉、白配色为灵感的 [Telegram Desktop](https://desktop.telegram.org/) 主题，提供日间与夜间两种版本。

## 使用方法

1. 下载喜欢的 `.tdesktop-theme` 文件。
2. 在 Telegram Desktop 中将文件发送到「收藏夹 / Saved Messages」，然后点击文件打开主题预览。
3. 点击「应用此主题 / Apply This Theme」，再点击「保留更改 / Keep Changes」。

安装步骤可参考 [Telegram 官方说明](https://telegra.ph/Set-Theme-Desktop-FAQ)。
